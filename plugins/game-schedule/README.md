# Game days

Every game for the kids' teams, on the family's calendar, with when to leave.

- **Set up, per team:** open Game days, Add a team: whose team, its name ("Soccer"), its calendar link, how long
  the drive usually is, and how early to be there. The link is in the team's app: TeamSnap (Schedule, Export or
  Subscribe), GameChanger (Schedule, Sync to calendar), SportsEngine and LeagueApps (Subscribe to calendar), or a
  Google Calendar's secret iCal address.
- **The calendar:** each game is an event "From Game days" (read-only there), with the kid and the place.
- **Today:** on a game day, one line until it starts: "Sam's Soccer: leave by 5:35 for 6:00 at Lincoln Park".
- **The voice:** "when's Sam's next game?", "is there a game this weekend?"

Leave-by times come from the drive time the household gives each team, not from the Map: Opie's Map is for the
household's own apps, not a plugin's. A league's web page (no calendar link) isn't read.

## What it asks for

- the family's names (whose team)
- a line of its own on Home
- events of its own on the calendar (it can't change the family's)
- reaching the team apps' calendar hosts: `calendar.google.com`, `*.teamsnap.com`, `*.gc.com`, `*.sportsengine.com`,
  `*.leagueapps.com`, `*.icloud.com`, `outlook.office365.com`, `outlook.live.com`, `*.teamapp.com`,
  `*.demosphere-secure.com`
