# For the sitter

One page with what a babysitter needs, big enough to read from across the room.

- **Set up:** open For the sitter and tap Write it: who to call (and where they'll be), each kid's bedtime and
  anything to know about them, allergies, the Wi-Fi name and password, the home's address for 911, and anything else.
  Change it any time.
- **The voice:** "show the babysitter card" opens it.
- Nothing leaves the tablet. Anyone at the tablet can open the page, so keep it to what a sitter should know.

## What it asks for

- the family's names (a row for each kid)
- it can't reach the internet
