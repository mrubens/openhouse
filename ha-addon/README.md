# Opie for Home Assistant

[![Add the repository to Home Assistant](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fmrubens%2Fopie-home-assistant)

Opie's hub as a Home Assistant add-on: the household's day, lists and apps on every phone, computer and TV, and Opie
to ask, already connected to your Home Assistant.

In Home Assistant: **Settings → Add-ons → Add-on store → ⋮ → Repositories**, add
`https://github.com/mrubens/opie-home-assistant`, then install **Opie**. See [opie/DOCS.md](opie/DOCS.md).

Opie itself, and how this add-on's image is built: https://github.com/mrubens/openhouse
